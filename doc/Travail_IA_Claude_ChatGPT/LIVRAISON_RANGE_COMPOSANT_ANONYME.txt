LIVRAISON -- 'RANGE sur composant array a sous-type contraint anonyme
=======================================================================
Format : une modification = ANCRE (texte existant unique, inchange)
+ bloc SUPPRIMER + bloc REMPLACER. Tabulations preservees. ASCII strict.


=======================================================================
COMMIT C -- expander : CODE_RANGE_ATTRIBUTE_BOUND, correctif record
=======================================================================
Fichier : expander-expressions.adb
Site : CODE_DISCRETE_RANGE_BOUND . CODE_RANGE_ATTRIBUTE_BOUND,
branche RAW_PREFIX.TY = DN_SELECTED (cartouche A62006D).

Motif : pour X.D'RANGE ou D est un composant array a sous-type
contraint ANONYME, XD_SOURCE_NAME remonte au type de base (piege
n 99) ; le patron NON contraint n'a ni _FST_n ni _LST_n -> symbole
fasm indefini (._LIMB_VECTOR._FST_1). Le CD_LEVEL, lui, etait deja
correct (pose par le correctif record d'INSERE_LES_CHAMPS). Remede
aligne sur CODE_SLICE / CODE_INDEXED (correctif record, temoin
REC_ARR_TEST 37) : bornes lues au bloc info ELABORE du composant,
_<comp>__type, chemin REGIONS_PATH( SEL_DEFN ) -- qui traverse le
namespace du record ( ..._BIG._D__type._FST_1 ). Sous-types NOMMES
et noms etendus PACK.OBJ : chemin historique conserve.

--- MODIF C1 ----------------------------------------------------------
ANCRE (unique, inchangee) :
	if  PREFIX_TYPE.TY = DN_CONSTRAINED_ARRAY  or else  PREFIX_TYPE.TY = DN_ARRAY  then

SUPPRIMER (bloc immediatement sous l'ancre) :
	  declare
	    TYPE_NAME	: TREE		:= D( XD_SOURCE_NAME, PREFIX_TYPE );
	    TYPE_STR	:constant STRING	:= TYPE_INFO_STR( PREFIX_TYPE );
	    TYPE_LVL	: INTEGER		:= DI( CD_LEVEL, PREFIX_TYPE );
	  begin
	    PUT( tab & "LD" & tab & IMAGE( TYPE_LVL ) & ", " );

	    if  TYPE_LVL /= INTEGER( CODI.CUR_LEVEL )  or else  D( XD_REGION, TYPE_NAME ).TY = DN_PACKAGE_ID
	    then
	      REGIONS_PATH( TYPE_NAME );
	    end if;

	    PUT( TYPE_STR & "." );

REMPLACER PAR :
	  declare
	    TYPE_NAME	: TREE		:= D( XD_SOURCE_NAME, PREFIX_TYPE );
	    TYPE_STR	:constant STRING	:= TYPE_INFO_STR( PREFIX_TYPE );
	    TYPE_LVL	: INTEGER		:= DI( CD_LEVEL, PREFIX_TYPE );
	    SEL_DEFN	: TREE		:= D( SM_DEFN, D( AS_DESIGNATOR, RAW_PREFIX ) );
	  begin
	    PUT( tab & "LD" & tab & IMAGE( TYPE_LVL ) & ", " );

	    if  SEL_DEFN.TY = DN_COMPONENT_ID
	    and then  D( SM_TYPE_SPEC, TYPE_NAME ) /= PREFIX_TYPE
	    then
	      -- Composant array a sous-type contraint ANONYME (piege n 99) :
	      -- XD_SOURCE_NAME remonte au type de BASE, dont le patron non
	      -- contraint n'a ni _FST_n ni _LST_n.  Les bornes sont LUES au
	      -- bloc info ELABORE du composant, _<comp>__type, meme regle
	      -- que CODE_SLICE / CODE_INDEXED (correctif record).
	      REGIONS_PATH( SEL_DEFN );
	      PUT( '_' & PRINT_NAME( D( LX_SYMREP, SEL_DEFN ) ) & "__type." );

	    else
	      if  TYPE_LVL /= INTEGER( CODI.CUR_LEVEL )  or else  D( XD_REGION, TYPE_NAME ).TY = DN_PACKAGE_ID
	      then
	        REGIONS_PATH( TYPE_NAME );
	      end if;

	      PUT( TYPE_STR & "." );
	    end if;

NOTE C1 : la suite du bloc (if IS_LAST ... PUT_LINE( IMAGE( NUM_DIM ) );
return;) est inchangee ; le test d'anonymat est le MEME que celui de
CODE_SLICE (D( SM_TYPE_SPEC, nom ) /= type), equivalent a la decision
USE_LOCAL_INFO d'INSERE_LES_CHAMPS -- un composant avec contrainte
explicite produit toujours un noeud anonyme, donc le bloc _<comp>__type
existe des que ce chemin est pris.
