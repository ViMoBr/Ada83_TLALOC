LIVRAISON TC-07c — le point final du prefixe est LE SEPARATEUR
  (fidelite stricte a la concatenation fasmg)
=======================================================================

COMMIT 1 — "CALL/LSPA : concatenation fidele prefix & subname (le
            point final du prefixe est le separateur, fourni par
            l'appelant) ; temoin corrige ; charite retiree"

LECON (a verser en NOTE v2 par 1.1) : le # de fasmg COLLE les
lexemes — "CALL STANDARD, SP7" fabrique STANDARDSP7. Le point final
des prefixes (releve EXP-03) n'est pas un artefact d'emission :
c'est LE SEPARATEUR, a la charge de l'appelant. TARGET_CODE
acceptait la forme nue en ajoutant le point (PASSE call obtenu sur
un FAS que fasmg REFUSE) : divergence de langage, interdite —
l'assembleur natif ne doit jamais etre plus indulgent que
l'implementation de reference. Apres ce commit, la forme nue produit
chez TARGET_CODE le meme verdict que chez fasmg : nom soude, corps
jamais atteint, echec bruyant a la resolution.

ORACLE : septuple PASSE ; fasmg TC_TEST7.FAS assemble DESORMAIS ;
cmp TC_REF7 muet ; ./TC_TEST7.BIN -> 0.

REMPLACER PAR :
<<<<

	      G		: constant STRING

	      CUT	: NATURAL	:= 0;

	      end loop;
	      if CUT = 0
	      then							--| prefixe SANS point : nom soude — la garde

			      G( CUT + 1 .. G'LAST ) );
	      end if;
	    end;
