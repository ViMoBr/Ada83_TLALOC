LIVRAISON EXP-01 — expander : marque de type SELECTIONNEE dans le
profil de retour d'une fonction (return PACK.TYPE)
=======================================================================

DIAGNOSTIC (bissection selfun_test / selfun_test2, aout 2026) :
  selfun_test v1 (return SL, marque SIMPLE) passe entierement ;
  selfun_test2 (return LEXX.SL, marque SELECTIONNEE) plante l'expander
  sur les QUATRE sites qui consultent le profil de retour : le
  "return R" du corps (CODE_RETURN) et chaque appel (preparation du
  lieu-resultat record), y compris en forme d'appel NON qualifiee —
  preuve que la faute est dans la MARQUE du profil, pas dans le nom
  d'appel. Les deux lecteurs font D( SM_DEFN, <marque> ) sans
  descendre le DN_SELECTED jusqu'au designateur, ou le semantiseur
  pose SM_DEFN (meme mecanique que les noms etendus d'objets, classif
  IDL.LIB_PATH du 6 aout, et que le PILIER 11 EXCEPTION_ID_OF).
  Piege VIERGE depuis l'origine : le corpus n'ecrit jamais
  "return PACK.TYPE" (style use / meme package). Revele par
  TARGET_CODE (IR.LAZY_OF retourne LEX.SLICE).

REMEDE : envelopper la marque par CODI.LAST_OF_SELECTED (helper
EXISTANT, expander-utils : descend les DN_SELECTED jusqu'au
designateur, identite sur un nom simple). Deux sites.

MEMES-FAMILLE, NON PAYES PAR CE TEMOIN (a durcir le jour ou un
temoin les paiera, doctrine n 53) :
  - expander-declarations.adb:2308  (WRAP_RESULT_TYPE, en-tete de
    wrapper generique : une instance generique de fonction retournant
    PACK.TYPE tombera au meme endroit) ;
  - expander-expressions.adb:6970   (marque d'appartenance
    "X in PACK.T", CODE_MEMBERSHIP).

PIEGE A CONSIGNER (numerotation a ta main) :
  Les marques de type SELECTIONNEES (PACK.TYPE) dans les profils —
  retour de fonction, et par extension appartenance et formels — ne
  sont pas descendues au designateur avant lecture de SM_DEFN.
  Corpus historique aveugle (style use). Temoins : selfun_test
  (marque simple, vert), selfun_test2 (marque selectionnee).

            (CODE_RETURN + lieu-resultat d'appel) ; temoin
            selfun_test2"

  1) selfun_test2.adb ENTIEREMENT decommente (les quatre sites
     "PROBLEME DEFN ICI" retablis, y compris le return R) compile,
     s'expanse, s'assemble et s'execute : "PASSE selfun_test2",

     TOUTE fonction, la marque simple doit produire un arbre

  3) reprise du temoin P0 de TARGET_CODE : la forme directe
     IR.LAZY_OF( IR.ELT_ID( E ) ).F redevient legale — le
     contournement TC-02d peut rester en place, sa simplification
     est optionnelle.
