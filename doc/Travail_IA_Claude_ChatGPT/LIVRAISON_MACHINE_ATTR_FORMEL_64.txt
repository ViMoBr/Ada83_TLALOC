LIVRAISON -- attributs MACHINE_* d'un type formel : famille 64 bits
====================================================================
Format : une modification = ANCRE (texte existant unique, inchange)
+ bloc SUPPRIMER + bloc REMPLACER. Tabulations preservees. ASCII strict.


====================================================================
COMMIT E -- expander : FLOAT_BITS, type formel digits <> = double
====================================================================
Fichier : expander-expressions.adb
Site : CODE_ATTRIBUTE . FLOAT_BITS (commutateur commun de
MACHINE_MANTISSA / MACHINE_EMAX / MACHINE_EMIN / EPSILON / SMALL /
LARGE / DIGITS machine).

Motif : pour un type FORMEL generique (digits <>), PREFIX_TYPE_SPEC
rend un DN_FLOAT dont CD_IMPL_SIZE <= 32 (pose par le front-end) ->
famille single (24 / 128 / -125). Or dans le modele du corps partage,
TOUT actuel flottant est represente en double a l'execution
(conventions : FLOAT et LONG_FLOAT tous deux en double ; CVTIF et
FMUL/FDIV 64 bits dans le FINC). Temoin : FLOAT_IO(LONG_FLOAT).GET
parametre P=24/EMAX=128 -- 1.0E38 arrondi a 24 bits de significande
(0x47D2CED320000000 au lieu de 0x47D2CED32A16A1B1, arrondi 24 bits
EXACT : la mecanique de GET est saine), 0.1 idem, 0.5 et -2.5 exacts
sur 24 bits donc inchanges, 1.0E308 -> DATA_ERROR (E=1023 > 127).

--- MODIF E1 -------------------------------------------------------
ANCRE (unique, inchangee) :
    function	FLOAT_BITS	return INTEGER

SUPPRIMER (corps du if, sous la declaration de T et le begin) :
      if T /= TREE_VOID and then T.TY = DN_FLOAT then
        if DI( CD_IMPL_SIZE, T ) <= 32 then
	return 32;
        else
	return 64;
        end if;
      end if;

REMPLACER PAR :
      if T /= TREE_VOID and then T.TY = DN_FLOAT then

        if  IS_GENERIC_FORMAL_TYPE( D( XD_SOURCE_NAME, T ) )  then
	-- Type formel digits <> d'un corps generique PARTAGE : tout
	-- actuel flottant est represente en double a l'execution
	-- (conventions TLALOC -- FLOAT et LONG_FLOAT tous deux en
	-- double ; CVTIF / FMUL 64 bits dans le corps).  Les
	-- attributs MACHINE_* decrivent la representation machine :
	-- famille 64 (53 / 1024 / -1021), meme regle "valeur
	-- machine" que la branche 'DIGITS pour un formel non resolu.
	-- Temoin : FLOAT_IO(LONG_FLOAT).GET -- P=24 arrondissait
	-- 1.0E38 a 24 bits et refusait 1.0E308 (EMAX 128).
	  return 64;
        end if;

        if DI( CD_IMPL_SIZE, T ) <= 32 then
	return 32;
        else
	return 64;
        end if;
      end if;

ORACLE COMMIT E :
 1. Recompiler text_io.adb ; dans TEXT_IO.FINC, l'elaboration des
    constantes de GET_L71 passe de
      LI	 24   /  LI	 128   /  LI	-125
    a
      LI	 53   /  LI	 1024  /  LI	-1021
    (P, MAX via MACHINE_EMAX, MIN via MACHINE_EMIN).
 2. Temoin fasmg : le texte
      LIF	0.1
      LIF	0.5
      LIF	1.0E38
      LIF	1.0E308
      LIF	-2.5
    assemble par target_code donne un BIN identique octet a octet a
    la reference fasmg (cmp vide) -- en particulier 1.0E38 emet
    ...B1 A1 16 2A D3 CE D2 47 et 1.0E308 est ACCEPTE.
 3. Vecteurs numeriques de l'oracle du COMMIT B (livraison GET FLOAT
    STATIQUE) contre gnat, bit a bit -- desormais significatifs
    puisque P=53 : ties pairs/impairs, frontieres normal/subnormal,
    sticky au-dela de 800 chiffres.
 4. Non-regression : attributs MACHINE_* sur types NON formels
    (FLOAT'MACHINE_MANTISSA hors generique) inchanges -- la branche
    CD_IMPL_SIZE est intacte ; filet complet + T2, diff FINC vide
    hors corps generiques utilisant ces attributs sur un formel.
