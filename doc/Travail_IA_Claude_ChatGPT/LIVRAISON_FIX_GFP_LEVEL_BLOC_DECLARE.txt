LIVRAISON_FIX_GFP_LEVEL_BLOC_DECLARE.txt
=========================================

Segfault TEST_CALENDAR / FLOAT_TEST / FLOAT_FIXED_IO_TEST (0x40697a).
Piege n 144, RESERVE levee : depuis un bloc declare d'un corps
generique, CUR_LEVEL est le niveau du BLOC (frame propre, sans PRM
GFP_ofs). Le site CODE_VC_ID (corrige GENERIC_BASE_LEVEL+1 -> CUR_LEVEL
pour MAKE_FLOAT imbrique dans GET) emet `LA 2, -GFP_ofs` dans
BLOCK__29 de FLOAT_IO.PUT : [display(2) - GFP_ofs] tombe dans la pile
d'operandes sous le frame du bloc (VAL = 8.639975 lu comme pseudo-GFP,
puis [pseudo-GFP - 0x20] = NUM__inadr_ofs -> faute).

Principe : ni CUR_LEVEL (faux dans un bloc) ni GENERIC_BASE_LEVEL+1
(faux dans un PRO imbrique). Le bon niveau est celui du PRO ENGLOBANT
LE PLUS PROCHE : celui dont le namespace resout le symbole GFP_ofs et
dont le frame porte ce PRM. Nouvelle variable CODI.GFP_LEVEL, posee
par CODE_SUBPROGRAM_BODY (et CODE_PACKAGE_BODY generique), jamais
touchee par CODE_BLOCK. GFP_LEVEL = CUR_LEVEL dans un PRO,
= niveau du PRO dans ses blocs, = GENERIC_BASE_LEVEL+1 a l'imbrication 1.

Conventions : tabulations preservees ; ASCII pur ; declarations
de base seulement (aucun corps intercale).
