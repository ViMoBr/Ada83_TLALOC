  "SONDES-VISEL : traces differentielle T1/T2 de la selection de littéraux"

Contexte : la resolution « visible par selection » d'un nom etendu

------------------------------------------------------------------------
MODIFICATION 1/4 — SONDEA : trace du filtre de la partie visible
------------------------------------------------------------------------
ANCRE (unique, inchangee) :
			  -- LOOK FOR ENTITIES DEFINED IMMEDIATELY WITHIN SPECIFICATION

SUPPRIMER (bloc unique, ~4 lignes sous l'ancre) :
	POP (TEMP_LIST, TEMP);
	if D (XD_REGION_DEF, TEMP) = NAME_DEF and then DB (XD_IS_IN_SPEC, TEMP) then
	  ADD_TO_DEFSET (NEW_DEFSET, TEMP);
	end if;

REMPLACER PAR :
	POP (TEMP_LIST, TEMP);
	Put_Line ("SONDEA " & PRINT_NAME (D (LX_SYMREP, DESIGNATOR)) & " CAND=" & NODE_NAME'IMAGE (TEMP.TY) & " REG=" & BOOLEAN'IMAGE (D (XD_REGION_DEF, TEMP) = NAME_DEF) & " SPEC=" & BOOLEAN'IMAGE (DB (XD_IS_IN_SPEC, TEMP)));
	if D (XD_REGION_DEF, TEMP) = NAME_DEF and then DB (XD_IS_IN_SPEC, TEMP) then
	  ADD_TO_DEFSET (NEW_DEFSET, TEMP);
	end if;

NOTE : ne PAS toucher la boucle jumelle de la branche region
(l. ~478-484, son test n'a pas le terme XD_IS_IN_SPEC).

MODIFICATION 2/4 — SONDEB1 : entree du bloc discard, tests de genre

ANCRE (unique, inchangee) :

------------------------------------------------------------------------
MODIFICATION 3/4 — SONDEB2 : comparaison d'interpretations + homographe
------------------------------------------------------------------------
ANCRE (unique, inchangee) :
	  TEMP_DEFSET := NEW_DEFSET;

SUPPRIMER (ligne unique) :
	    TEMP_DEFINTERP := HEAD (TEMP_DEFSET);

REMPLACER PAR :
	    TEMP_DEFINTERP := HEAD (TEMP_DEFSET);
	    Put_Line ("SONDEB2 NE=" & BOOLEAN'IMAGE (TEMP_DEFINTERP /= OLD_DEFINTERP) & " HOMO=" & BOOLEAN'IMAGE (ARE_HOMOGRAPH_HEADERS (D (XD_HEADER, GET_DEF (OLD_DEFINTERP)), D (XD_HEADER, GET_DEF (TEMP_DEFINTERP)))));

ATTENTION : la sonde evalue ARE_HOMOGRAPH_HEADERS HORS de la garde
« NE » (le vrai code la court-circuite quand NE=FALSE). Si la
compilation du temoin plante dans la sonde, retirer le terme HOMO=
et garder NE= seul.

------------------------------------------------------------------------
MODIFICATION 4/4 — SONDEB3 : verdict garde/elimine
------------------------------------------------------------------------
ANCRE (unique, inchangee) :
	    POP (TEMP_DEFSET, TEMP_DEFINTERP);

SUPPRIMER (bloc unique) :
	  if IS_EMPTY (TEMP_DEFSET) then
	    ADD_TO_DEFSET (NEW_NEW_DEFSET, OLD_DEFINTERP);
	  end if;

REMPLACER PAR :
	  Put_Line ("SONDEB3 GARDE=" & BOOLEAN'IMAGE (IS_EMPTY (TEMP_DEFSET)));
	  if IS_EMPTY (TEMP_DEFSET) then
	    ADD_TO_DEFSET (NEW_NEW_DEFSET, OLD_DEFINTERP);
	  end if;

NOTE : ne PAS toucher le ADD_TO_DEFSET de la branche else (garde
inconditionnelle des non-littéraux), ni le bloc TEMP_DEFSET de la
l. ~635 (espacement different, hors sujet).

========================================================================
ORACLE DU COMMIT
========================================================================

Construction (deux executables) :
  T1s : vis_util instrumente compile sous gnat, edition des liens de T1.
  T2s : vis_util instrumente compile par T1, edition des liens de T2
        (SEULE cette unite recompilee — le reste des objets T2 inchange).

Execution : compiler ../visel2_test.adb par T1s puis par T2s, capturer
stdout, puis diff des deux traces. La PREMIERE divergence designe la
construction source mecompilee.

Trace attendue T1s (reference saine), extrait pour C := NP.RED —
le nom exact du genre de noeud littéral (ici note <LIT_ID>) est a
relever dans la trace T1s elle-meme :

  SONDEA RED CAND=<LIT_ID> REG=TRUE SPEC=TRUE
  SONDEB1 <LIT_ID> OP=FALSE LIT=TRUE INS=FALSE
  SONDEB2 NE=FALSE HOMO=TRUE
  SONDEB3 GARDE=TRUE

(HOMO=TRUE est normal : homographe de soi-meme ; dans le vrai code
NE=FALSE court-circuite ce test. Un seul SONDEB2 attendu : l'ensemble
est un singleton.)
Pour NP.CONST : SONDEA ... REG=TRUE SPEC=TRUE puis SONDEB1 ... LIT=FALSE
INS=FALSE, PAS de SONDEB2/B3 (branche else), et resolution muette.
T1s doit rester muet en diagnostics et VISEL2_TEST (compile par T1s puis
execute) doit toujours rendre « RESULTAT : 6 OK / VISEL2_TEST PASSE ».

Grille de lecture de la trace T2s (premiere divergence) :

  1. SONDEA REG=FALSE ou SPEC=FALSE sur le littéral (TRUE sur CONST)
     => la mutilation est en AMONT du bloc discard : egalite du record
     TREE (32 bits, clause de representation, champs a cheval) ou
     lecture d'attribut DB sur noeud littéral. Cible .finc : le code de
     « D (XD_REGION_DEF, TEMP) = NAME_DEF » (egalite composite d'un
     record a rep clause) dans vis_util.

  2. SONDEB2 NE=TRUE (B1 conforme, SONDEA conforme)
     => le « /= » de DEFINTERP_TYPE est mecompile (ou HEAD rend un
     element altere) : l'interpretation se voit differente d'elle-meme,
     se trouve homographe d'elle-meme, et le littéral est elimine.
     Cible .finc : la comparaison TEMP_DEFINTERP /= OLD_DEFINTERP.

  3. SONDEB1 LIT=FALSE sous T2s sur le littéral
     => test d'appartenance « in CLASS_ENUM_LITERAL » mecompile ;
     incompatible SEUL avec l'erreur observee (le littéral serait alors
     garde par la branche else) — croiser imperativement avec SONDEA.

  4. SONDEB3 GARDE=FALSE avec NE=FALSE partout et B1 conforme
     => HEAD / POP / IS_EMPTY sur DEFSET_TYPE en cause.

Garde-fou heisenbug : si T2s ne reproduit PLUS l'erreur sur visel2
(les Put_Line ajoutes changent le code genere autour du point fautif),
c'est une information en soi — retirer alors les sondes UNE PAR UNE
(ordre 4,3,2,1) jusqu'a reapparition, la derniere retiree encadre le
point fautif.
